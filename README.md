# Campus Service

## Goal
A small JavaScript service demonstrating version control, team collaboration, conflict resolution, and automated checks. The exported add(a, b) function returns the arithmetic sum.

## Run tests
Install Node.js 22 or later, then run:

```sh
npm test
```

No external npm packages are required. Tests use node:test and node:assert/strict.

## Tools used
- Visual Studio Code for editing project files
- TortoiseGit for repository initialization, commits, branches, merges, and pushes
- GitHub for the remote repository and pull requests
- GitHub Actions for automated testing on Ubuntu
- Node.js and npm for local and automated tests
